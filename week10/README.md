# Week 10 — Java Fundamentals Practice (Category C)

Each Java file is self-contained and reads the problem input from standard input. Problems with several sample inputs (prime check, factorial, grade, leap year, palindrome) read values until end of input.

Compile all solutions with:

```bash
javac week10/*.java -d out
```

Then run one solution, for example:

```bash
java -cp out VowelConsonantCounter
```
