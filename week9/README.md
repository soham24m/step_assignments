# Week 9 — Abstraction: Abstract Classes & Interfaces (Category C)

Each Java file is self-contained and reads the problem input from standard input. Every solution uses an abstract base class that holds the shared data and declares the type-specific calculation as an abstract method, so the reporting code works polymorphically.

Compile all solutions with:

```bash
javac week9/*.java -d out
```

Then run one solution, for example:

```bash
java -cp out GardenPlotAreaReport
```
